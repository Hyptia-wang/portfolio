王秋璇 · 动画制片 · 简约现代版个人网站

════════════════════════════════
一、如何打开
════════════════════════════════
1. 解压本 zip 到任意文件夹。
2. 双击「index.html」即可在浏览器打开，无需安装任何环境。

════════════════════════════════
二、页面结构
════════════════════════════════
· index.html    首页（首屏带入场动画）
· works.html    作品集（含 3 个扩充占位卡，可替换为你的作品）
· about.html    关于我
· contact.html  联系（含表单验证）

共享文件：
· css/style.css  全站样式（燕麦绿调 · 简约现代）
· js/main.js     交互脚本（导航/滚动动画/表单验证）
· favicon.svg    站点图标

════════════════════════════════
三、动画说明
════════════════════════════════
· 首屏入场动画（rise）：页面加载即触发，标题/副标题/按钮等依次上浮淡入。
· 滚动动画（reveal）：滚动到元素进入视野时上浮淡入。
· 顶部进度条：随页面滚动显示阅读进度。

════════════════════════════════
四、如何扩充作品集
════════════════════════════════
打开 works.html，在「更多作品 / 作品扩充区」找到占位卡，
将 <div class="card-placeholder"> 整段替换成已有的 .card 作品卡片结构即可。

════════════════════════════════
五、自定义
════════════════════════════════
· 联系方式：在 contact.html 中把「待补充」替换为你的邮箱 / 城市。
· 配色：在 css/style.css 顶部的 :root 变量里调整 --sage-* / --accent 等。
